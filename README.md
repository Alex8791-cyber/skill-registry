# Cognithor Community Skill Registry

Public registry for community-contributed Cognithor skills.

## Structure

- `registry.json` — Skill index (name, version, hash, publisher)
- `publishers.json` — Verified publisher identities and trust levels

## Publishing a Skill

See the [Cognithor documentation](https://github.com/Alex8791-cyber/cognithor) for details on creating and publishing community skills.
